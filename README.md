# کیس متر

اپلیکیشن فارسی و موبایل‌فرست برای **غزاله** — امتیاز بده به پسرها، جدول رتبه‌بندی ببین، و گردونه شانس را بچرخان.

## اجرا

```bash
npm install
cp .env.example .env.local
# DATABASE_URL را با Postgres واقعی پر کن
npm run dev -- --port 43127
```

سپس باز کن: [http://127.0.0.1:43127](http://127.0.0.1:43127)

## امکانات

- افزودن پسر با ۱۴ معیار امتیاز ۱ تا ۱۰
- جدول از بالاترین تا پایین‌ترین امتیاز
- دو نفر ثابت (غیرقابل حذف/ویرایش) با حداکثر امتیاز: **حمید افقه** و **سیامک قدسی**
- گردونه شانس (همیشه همان نتیجه خاص را نشان می‌دهد)
- ذخیره در Postgres (مناسب دیپلوی روی Vercel)

## دیپلوی روی Vercel

1. در [Vercel Git settings](https://vercel.com/siaamaks/~/settings/git) اتصال **Origin** را فعال کن (یا ریپو را به GitHub بفرست).
2. پروژه Next.js را ایمپورت کن.
3. متغیر محیطی `DATABASE_URL` را از Prisma Postgres همین پروژه ست کن (همان مقدار `.env.local`).
4. Deploy

تا وقتی Origin وصل نشده، لوکال با `npm run dev` کار می‌کند.
